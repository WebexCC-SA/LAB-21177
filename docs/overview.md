# Overview

## Learning Objectives

The overall objective of this comprehensive lab session is to give audience end-to-end, hands-on experience in building, optimizing, and troubleshooting core voice workflows in Webex Contact Center (WxCC). Throughout this multi-module labs, you will step into the shoes of a contact center administrator to tackle real-world deployment challenges, dynamic routing paradigms, and latest AI routing features.

By navigating through  these curated lab exercises, you will master:

* **Inbound Call Flows & Operations (Lab 1):** Discover existing tenant configurations, build inbound flows, team-based distribution strategy, and analyze agent performance events like Re-Route on No Answer (RONA).


* **Call Flow Diagnostics & Transfer Fixes (Lab 2):** Identify, isolate, and repair critical call flow transfer failures that lead to dead air and dropped calls.


* **Skill-Based Routing & Variable Logic (Lab 3):** Master Skill-Based Routing (SBR) by creating proficiency/boolean skill profiles and leveraging Flow Builder variables to dynamically route callers to the most qualified resources based on IVR inputs.


* **Blind Transfer Dynamics & Lifecycle Analytics (Lab 4):** Resolve "Skill Carryover Conflicts" when performing blind transfers from the Agent Desktop to skill queues, apply corrective routing logic, and construct end-to-end multi-leg call journey reports in WxCC Analyzer.


* **Personalized AI Routing (Lab 5):** Configure multi-dimensional AI matchmaking, execute bulk optimization checks, and analyze predictive handle-time reduction models using Shadow and Evaluation modes.


* **Outdial Capabilities & Diagnostics (Lab 6):** Configure complete outbound dialing workflows from scratch and debug implementation errors to guarantee operational reliability.


* **WebRTC Call Data & Audio Diagnostics (Lab 7):** Inspect available WebRTC call data and statistics using built-in browser tools while simulating and troubleshooting missing audio scenarios during active calls
